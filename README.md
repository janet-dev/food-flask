# Food Reviews Flask REST API

# This is a Flask web application that provides a RESTful API for managing food reviews.  
## It supports full CRUD (Create, Read, Update, Delete) operations on reviews.

---

## Project Purpose

## This project allows users to submit, view, update, and delete food reviews via API endpoints.  
## It aims to demonstrate building a clean REST API with Flask and SQLAlchemy.

---

## Features

## - Create new food reviews  
 ## - Retrieve all reviews or a single review by ID  
##  Update existing reviews  
## Delete reviews  
# Proper error handling with HTTP status codes  
## JSON request and response format
